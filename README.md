# AcessHub

## Descrição
O **AcessHub** é uma aplicação IoT que integra uma **fechadura eletrônica** com um **sistema web** e **Firebase**, permitindo um controle de acesso seguro e eficiente. O projeto combina hardware e software, possibilitando a gestão de usuários e monitoramento de entradas em tempo real.

---

## Tecnologias Utilizadas
- **Hardware/IoT:** ESP32, sensores e atuadores
- **Backend/Web:** JavaScript, Firebase (Authentication e Realtime Database)
- **Frontend:** HTML, CSS, JavaScript
- **Controle de acesso:** Sistema web integrado ao Firebase para autenticação e monitoramento

---

## Objetivo
O projeto tem como objetivo **proporcionar um sistema de controle de acesso moderno e seguro**, permitindo que usuários autorizados possam acessar ambientes controlados via fechadura eletrônica, enquanto administradores gerenciam permissões e monitoram entradas pelo sistema web.

---

## Funcionalidades Principais
- **Autenticação de usuários:** Login via email e senha utilizando Firebase Authentication
- **Controle de acesso:** Acionamento remoto da fechadura eletrônica via sistema web
- **Monitoramento em tempo real:** Registro e visualização de entradas e saídas pelo Firebase Realtime Database
